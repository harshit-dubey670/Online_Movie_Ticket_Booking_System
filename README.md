# Online Movie Ticket Booking System

An interactive and user-friendly web application developed for booking movie tickets online. This project allows users to browse movies, view show timings, select seats, and book tickets seamlessly through a responsive interface.

## Features

* User-friendly and responsive design
* Browse latest movies and show details
* Seat selection functionality
* Movie timing and booking system
* Secure login/signup authentication
* Online ticket reservation interface
* Fast and smooth user experience

## Technologies Used

### Frontend

* React.js
* Tailwind CSS
* JavaScript
* HTML5
* CSS3

### Backend

* Node.js
* Express.js

### Database

* MongoDB

## Project Purpose

The main objective of this project is to simplify the movie ticket booking process by providing an online platform where users can easily reserve tickets without standing in queues.
